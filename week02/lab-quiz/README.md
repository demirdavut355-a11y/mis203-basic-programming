In Python, the input() function always captures data as a string . Performing operations on strings leads to string concatenation rather than mathematical calculation . To perform arithmetic operations such as multiplication and calculating percentages, string inputs must be explicitly cast to numerical types using int() for whole quantities and float() for decimal monetary values.
Resolution in later versions: This can be handled by wrapping the input conversion in a try - except ValueError block to catch invalid entries gracefully, or by using a while loop with .isdigit() validation to repeatedly prompt the user until a valid integer is provided.
